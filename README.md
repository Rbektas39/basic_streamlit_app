# 🐧 Penguin Explorer (Streamlit App)

An interactive Streamlit application built using the Palmer Penguins dataset to explore relationships between species, island, sex, and body mass.

---

## 📊 Overview

This app allows users to filter and explore penguin data dynamically, demonstrating basic data exploration and visualization using Streamlit.

---

## ⚙️ Features

- Interactive filtering by:
  - Species
  - Island
  - Sex
  - Body mass range
- Display of dataset using a pandas DataFrame
- Summary statistics for numerical variables
